# Project screenshots

Put one screenshot per project here, named after the project in lowercase
with dashes (for example `weather-app.png`). Wide images (about 16:9) work
best, since project cards crop images to a short banner.

Then point that project's card in `portfolio.html` at the file:

```html
<img src="images/projects/weather-app.png" alt="Weather App screenshot">
```

Cards without a screenshot yet can keep using `images/placeholder.jpg`.
